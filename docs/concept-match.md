# 按整张概念图重建的视觉对照

2026-11-01。最新要求为“跟概念图一样，摄影级细节”。这次范围覆盖整张画面，更新了之前仅精修特效的范围；第二、三阶段仍未开始。

基准为用户最新上传的 [photographic-reference.png](../design/photographic-reference.png)，与已确认的桌面方向一致。桌面按 **1585 × 992** 原尺寸截取真实浏览器画面，手机保留既有上下布局并增强彩色星点。运行时未加载概念图、参考视频或静态蛋糕图片。

## 重建内容与实际修正

| 部位 | 旧版差距 | 本次实现 |
| --- | --- | --- |
| 蛋糕 | 糕体偏高，顶部是紫色平盘和一圈白球 | 调整高宽比例，改为完整象牙白奶油顶；连续网格生成十五处不同宽深的滴落，卷边与底面有圆滑过渡 |
| 裱花 | 缺少真实褶皱与尖端 | 十朵独立实例；扭转八瓣截面、浅螺旋纹、偏转尖端和细微尺寸差异；对照截图后修掉管状建模产生的黑色层间缝 |
| 材质 | 大块高亮星云，表面像光滑塑料 | 蓝紫粗糙奶油、细孔凹凸、少量物理金色碎糖；顶部奶油加入微纹理，糖珠使用有环境反射的物理材质 |
| 蜡烛 | 细棍与金属线，比例不符 | 加粗象牙色蜡体与细螺旋浮雕，收细体积火焰，使暖白核心、橙色外焰与微小焰根保持可辨识 |
| 底盘 | 平黑圆柱，偏低 | 薄弧面轮廓、金色细沿与程序化蓝紫纹理；修正高度和反光 |
| 布光 | 主体偏平，奶油没有接触层次 | 柔光环境、暖色主光、冷色轮廓光、PCSS 柔影；桌面加入小半径环境遮蔽。降低半径与强度，避免裱花和蜡烛发黑 |
| 星轨与星空 | 星轨范围窄，小星暗且缺少包围感 | 三轨扩大并重调倾角；轨道大珠改为真实受光材质；近景彩点扩大分布，补上低亮程序化星云和细星尺寸补偿 |
| 构图与控制栏 | 主体和底盘偏低，栏宽与位置不符 | 校准桌面镜头、底盘、栏宽和底部间距；手机扩大可视范围，修掉新增大轨道在边缘的裁切 |

蛋糕、奶油、底盘、糖珠、蜡烛均为三维网格；火焰为射线积分密度场，星砂与粒子为 GPU Points，星轨有正确的前后遮挡。暂停后拖动仍会改变受光、切面闪光和体积观察方向。

检查范围包括入场、拖动、暂停/恢复、五秒自动旋转恢复、生日高潮、五轮重播、手机触控、375/390/412 尺寸、低性能档、减少动态效果、隐藏页时钟及 WebGL 不可用提示。生产构建包含 TypeScript 检查。曾在回归中抓到底盘 shader 的预处理换行错误，修正后重新执行完整回归；不能以构建成功代替 GPU shader 验证。

桌面仍为 8,706 个源 Points。环境遮蔽增加一次几何绘制，因此 `gl.info.render.points` 为 17,412；手机为 5,280，低档为 2,774。没有以翻倍的粒子预算换取视觉增强。性能数字仅代表本机 Chrome 与模拟手机视口，不代表手机实机。

最终生产构建回归：14 项检查通过，控制台错误列表为空。五轮重播始终为 49 个 geometry、39 个 texture。桌面稳定/高潮为 59.76 / 59.76 FPS；390 模拟视口稳定/高潮为 59.82 / 59.77 FPS。上述为本机约 2.5–3 秒采样结果，不代表手机实机性能。
