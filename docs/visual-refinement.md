# 按原片重新制作星河主视觉

> 本文件记录上一轮视频视觉修订。用户随后提供明确近景截图，当前目标与最新结果见 [image-target-refinement.md](image-target-refinement.md) 和 `qa-image/`。

2026-11-01，用户实看初版后反馈“需要跟参考视频一样”“太单调，不太精致”。本次以视频约 10–13 秒的蓝色星砂圆形蛋糕为主要视觉依据，替代初版偏普通奶油蛋糕的处理。保留第一阶段交互和原创页面 UI，没有提前加入第二、三阶段功能。

## 实际变化

| 对照点 | 初版问题 | 新版 |
| --- | --- | --- |
| 糕体 | 大面积较平的紫色圆柱 | 深蓝、钴蓝、紫色多尺度云纹、程序化凹凸与清漆材质，表面真实三维星砂 |
| 顶面 | 大块白色奶油，风格偏普通蛋糕 | 紫色星砂糖霜，细内圈光环与连续的 52 颗奶油珠圈，接近原片的蓝色主题 |
| 奶油与糖珠 | 螺旋花形过简，表面反射偏平 | 珍珠奶油边、细糖珠、金色糖片；程序化环境柔光提供真实高光，无外部 HDR 素材 |
| 星轨 | 环线太宽，像三条装饰绳 | 收紧到蛋糕周围；每轨有独立运动的细密散射星尘，减少大轨道珠子 |
| 周围星河 | 彩点稀疏，缺少原片的包围感 | 细白星尘、蓝粉青金彩点、四角星芒、小方片分层，集中环绕糕体与火焰下方 |
| 火焰 | 窄小、偏单色 | 更饱满的白黄内焰、金黄色主焰、橙红外焰、蓝色焰根及上升金色火星 |
| 手机构图 | 主体偏小 | 放大约 9%，完整保留轨道与底部独立操作区 |

原片是屏幕实拍，无法取得其真实材质、灯光或粒子算法。新版匹配可观察到的主体、颜色、密度、粒子尺寸层次和运动关系，不把“跟参考一样”表述为原网站源码或逐像素复刻。

所有糕体、星砂、珠圈、轨道、火焰和庆祝效果仍实时渲染。没有使用概念图或视频替代画面。UI 文案、暂停、重播、生日高潮及祝福流程保持第一阶段要求。

## 预算调整

新增细尘与糕体星砂使用预分配 BufferGeometry + shader；重复糖珠和糖片使用 InstancedMesh，不创建数千个 React 粒子组件。细尘以小尺寸点为主，彩色近景大点数量保留原有预算。

| 档位 | 彩色近景 | 远景 | 体积细尘 | 糕体星砂 | 每轨细尘 | 火星 | 爆发 | GPU Points 总数 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 桌面 | 600 | 700 | 2400 | 3200 | 400 | 128 | 350 | 8578 |
| 手机 | 300 | 400 | 1200 | 1800 | 400 | 96 | 220 | 5216 |
| 低档 | 150 | 300 | 600 | 1000 | 180 | 48 | 120 | 2758 |

DPR 上限仍为 2 / 1.5 / 1，稳定低帧率时自动减粒子与后期分辨率。实际 GPU Points 计数已与预算核对。

## 新版验收

`pnpm build` 的 TypeScript 和 Vite 生产构建通过。生产预览地址 `http://localhost:4173/`，自动化验收记录单独保存在 [`qa-refined/results.json`](qa-refined/results.json)，没有覆盖初版证据。

| 检查 | 新版结果 |
| --- | --- |
| 开场、入场、拖动、暂停/继续、惊喜、祝福 | 通过 |
| 5 秒自动旋转冷却 | 通过 |
| 五次完整重播 | 通过；每轮 46 个几何体、23 个纹理，未观察到该计数增长 |
| 390×844、375×667、412×915 | 无横向溢出，按钮触摸区域至少 44px；390 尺寸完成触摸操作链路 |
| 1585×992、1366×768 | 额外截图复核，见 `qa-refined/native-layouts.json` |
| 减少动态效果、可见性监听器模拟、低档 | 通过 |
| 受控低帧率自动降档 | 通过；约 20.63 FPS 时自动进入低档，GPU Points 实际降到 2758 |
| 自动化正常流程控制台 | 无应用、资源或 shader 错误 |

本机 Chrome 自动化环境短窗口采样：

| 场景 | 平均 FPS | 帧时 P95 |
| --- | ---: | ---: |
| 桌面稳定 | 59.73 | 16.9ms |
| 桌面庆祝 | 59.74 | 16.8ms |
| 手机 390×844 模拟稳定 | 59.56 | 16.8ms |

## 可视复核与浏览器确认

重新使用 `view_image` 查看原片联系表、新版桌面和手机实拍，核对了糕体配色、顶面、奶油珠圈、星砂密度、轨道形态、火焰、光照、主体比例和原生 UI 文案。主视觉依据现在是用户要求的原片，初版概念图只用于 UI 与构图参考。新版不宣称已获得用户视觉确认。

另通过浏览器操作工具刷新内置预览并打开已连接的常规 Chrome，直接截图确认画面。Canvas 的备用 HTML 原先被无障碍树列为内容，曾导致把备用 WebGL 提示误读为正在显示的错误；实际截图显示正常开场。现已将 Canvas 内的备用 HTML 从无障碍树隐藏，真正的渲染错误仍由外层错误边界显示可访问的说明和重试入口。

修正后再次在用户当前内置浏览器点击“开启星河”，等待 `main[data-phase="idle"]`，直接截图确认实时糕体、星砂、火焰与控制栏均显示正常；备用错误文案已不再进入正常页面的无障碍树。当前内置预览已留在新版稳定场景。
