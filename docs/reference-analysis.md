# 参考视频分析

## 分析依据与限制

原片是约 31.37 秒的电脑屏幕实拍，1920×1080、30 fps。分析覆盖全程逐秒画面，并对 10 秒以后蛋糕、编辑、切换与结尾部分检查了每 0.5 秒的细节帧。下述时间为近似值，不作为最终新网页的动画时长要求。

观察结果与拟实现方式需要区分：能从视频判断外观、运动和可见操作，但不能证明源码架构、粒子实现算法、麦克风检测、持久化或跨设备分享能力。所有观察到的品牌、图标和文案都不作为素材复用。

## 八个重点

### 1. 星河蛋糕主体结构

最初的星河蛋糕具有清晰圆柱胚体、独立奶油顶部和白色珠状奶油边缘、底盘、顶部蜡烛。蓝紫胚体表面有丰富星光细节。后半段可见方形、爱心、圆形及多层组合，奶油边、胚体和装饰可独立变化。编辑时部分部件被拉开，标注其身份。

新版保留层次和体积，采用原创蓝紫胚体、珍珠白奶油、少量糖珠、薄底盘；减少装饰密度。第一阶段仅实现圆形单层，但保持模型模块化。

### 2. 粒子动画

画面包含数量很密的细白星尘、较大的蓝粉黄金等彩色点、星形或碎片状亮点，以及火焰上方金色火星。尺寸变化明显，点状粒子有上下和环绕漂移，部分覆盖蛋糕前方，外围较疏。原片的主体包围感很强，但新设计需要保留黑色间隙，避免平面噪点遮住蛋糕。

新版区分远景星空、近景彩色漂浮粒子、轨道星尘。用户已明确选择增加彩色星点，主要加强近景和轨道附近，远景不相应堆密。

### 3. 火焰动画

原片中火焰偏大、偏亮，呈白黄核心及橙红外部，持续改变长短和宽度，上方有金色火星带。多根或数字蜡烛组合时，火焰数量随装饰变化。

新版使用实时 shader 制作更克制的火焰比例，表现摇摆、拉伸和闪烁，并通过局部暖光照亮奶油顶部。不能用静态 PNG。原片没有完整展示用户需求中“先未点燃、再火星聚集点燃”的全过程，新的点燃时间线按 PLAN.md 原创实现。

### 4. 环绕星轨

细亮点构成不同倾角的椭圆轮廓，环绕蛋糕上下，亮点沿路径运动，与蛋糕前后交错。可见底部环绕亮点与上方倾斜环线。它们承担了比普通星空背景更明显的空间提示。

新版明确设计三条不同倾角、半径和速度的三维轨道，保留正确深度遮挡；不能用屏幕空间二维椭圆覆盖蛋糕来替代。

### 5. 蛋糕切换效果

原片展示的是快速随机换款、换层级和装饰组合，也有分层展开和合拢。不同画面之间能看到蛋糕主体、奶油、底盘和蜡烛各自变化。不能从录像确定它们是何种具体动画库或插值算法。

新版第二阶段使用约 0.5–0.8 秒的 scale 和 opacity 过渡，不照搬原片的部件标注和拆装式布局。第一阶段不显示不可用的切换按钮。

### 6. UI 控制栏

原片底部是紫色多标签设置面板，包含蛋糕层、奶油、装饰、文字、蜡烛、底盘等分类，以及随机、合拢/拆开、导出和完成一类操作。设置内容在面板中展开，观看模式则收起大面板，边缘保留小型控制入口。实拍清晰度有限，不把难辨认的标签写成已确认功能。

新版重新设计半透明深色紧凑底栏；第一阶段仅有暂停/继续、重播和生日惊喜。后续桌面按需展开小面板，手机使用 Bottom Sheet。不复用原图标、标签编排或紫色面板样式。

### 7. 页面交互逻辑

可观察链路为：生日开场 → 进入蛋糕 → 展开编辑 → 随机/切换组合 → 完成并回到观看 → 庆祝 → 祝福文字。单凭视频无法确认拖动、缩放、保存和分享的全部细节。

新项目根据用户要求明确增加受限 OrbitControls、缓慢自动旋转、拖动后暂停并恢复。完整产品第二阶段再加入许愿和点击吹灭；第一阶段从稳定状态直接点击惊喜进入高潮。

### 8. 最后生日庆祝爆发

原片后段明显增加彩纸和飞散碎片，向四周扩散并落下；蛋糕、星河轨道和近景粒子持续存在。随后祝福浮层逐渐出现。没有证据表明原片存在完整 5–8 秒蓄光、火焰增强、中心三维爆发和姓名动画的连贯流程。

新版按需求原创约 7 秒高潮：UI 淡出、镜头靠近、星轨加速、火焰增强、中心 3D 粒子爆发、Happy Birthday 与姓名渐显、落到祝福。第一阶段实现基础爆发，第二阶段增加爱心、彩纸及吹灭烟雾。

## 原创设计与验收重点

- 保留星河围绕蛋糕的视觉逻辑、体积层次和“开场—观看—惊喜—祝福”的节奏。
- 不迁移原片的爱心卡片开场、Logo、品牌、密集标签编辑器、素材、图标或原文案。
- 背景避免大型摄影星云，主视觉始终是蛋糕和三维星轨。
- 与参考视频比较时关注运动、大小关系、空间感和高潮节奏；与 design/ 概念图比较构图、材质、配色、UI 与阅读性。
- 录像不提供麦克风吹气、跨设备分享、数据库或后端能力的可靠证明；按用户需求分阶段另行实现。
- 原始迁移时仅完成分析和概念图；2026-11-01 第一阶段已实现。新一轮全片复核、浏览器与性能结果见 [实现依据](implementation-notes.md) 和 [验收记录](acceptance-stage-1.md)。
