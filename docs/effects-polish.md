# 发光星砂、火焰和粒子精修（历史版本）

> 本文记录前一轮仅修特效的版本。最新用户要求已扩展为整张概念图，当前结果见 [concept-match.md](concept-match.md)。

2026-11-01。按用户最新澄清，保留当前发光星砂蛋糕造型与主要交互，工作范围是提升星砂、火焰和粒子本身的细腻度。最近上传图片保存在 [`design/effects-reference.png`](../design/effects-reference.png)，用于对照晶粒、光晕、火焰层次；没有将其加载为运行时画面。

## 这轮具体改动

- **星砂：** 移除大块高亮蓝色自发光斑，减少粗糙的随机噪声。将表面星砂独立为 `StarSand.tsx`，每粒带有微小切面朝向；镜头转动时，切面与半角方向的关系会改变亮度。底色、细小晶点和少量较亮的瞬时闪光分别控制，不靠全身 Bloom 糊亮。
- **火焰：** 将始终朝向相机的平面轮廓替换为三维密度场。通过局部相机射线在体积内积分颜色与透明度，呈现暖白内焰、橙金外焰、很小的蓝色焰根，以及微弱的弯曲和上升扰动。拖动查看时会重新穿过体积采样，不是旋转同一张火焰图片。桌面/手机/低档分别使用 40/30/20 步，受统一动画时钟控制。
- **漂浮粒子：** 去掉实心彩色圆片与粗星形，采用小亮核、渐隐的彩色光晕和少量细四角星芒；远景、近景、微尘和火星各自控制尺寸、亮度及闪烁速度，保持黑色间隙。
- **整体发光：** 收细火焰上升火星，降低大面积暖光池和光晕，收紧 Bloom 强度。使用近黑背景检查细小亮点的层次，使粒子不被灰色底和大范围泛光冲淡。

蛋糕几何造型、奶油圈、三条轨道、开场/高潮/祝福流程保持本轮开始时的结构；没有改为普通奶油蛋糕，也没有加入第二、三阶段功能。

## 验证

`pnpm build` 的 TypeScript 和 Vite 生产构建通过。生产预览运行于 `http://localhost:4173/`。

完整浏览器检查见 [`qa-fine/results.json`](qa-fine/results.json)：开启星河、旋转、暂停/继续、5 秒自动旋转冷却、高潮、祝福、五次重播、手机触摸、低档、减少动态效果和 WebGL 不可用提示均通过。正常流程控制台无应用、资源或 shader 编译错误。五次重播均为 48 个几何体、23 个纹理，未观察到对应计数增长。
