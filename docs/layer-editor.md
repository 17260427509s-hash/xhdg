# 第二阶段续作：逐层定制与编辑历史

> 历史记录：最新无标签、连续 morph 换款与精细糕体见 [cake-refinement.md](cake-refinement.md)。本文所述旧场景标签与缩放淡出换款已被替换，截图保留为历史。

日期：2026-11-03（Asia/Shanghai）。在 `cf3cdff` 的第二阶段与分层编辑基础上继续，未添加第三阶段服务或依赖。

## 用户可见变化

- 在“蛋糕 → 编辑范围”选择整体或第 1／2／3 层；也可直接点击展开场景中的糕体标签。点击标签会回到蛋糕设置，选中层高亮。
- 每层能独立修改圆形／方形／爱心、糕体颜色、奶油颜色及金星／草莓／水晶糖／爱心／无糖饰。其他层的定制保留，奶油几何与表面星砂跟随该层轮廓。
- 整体改色或改造型会同步各层对应属性；整体糖饰设置只用于顶层，不删除下层已有糖饰。可恢复单层或全部层的默认搭配。
- 新增撤销／重做按钮与 Ctrl+Z、Ctrl+Shift+Z／Ctrl+Y（Mac 使用 Command+Z／Command+Shift+Z）。输入框内保留原生文字编辑快捷键。最多保留 40 步会话历史，修改后清空重做分支。
- 减少层数时清理隐藏层配置并回到有效选择；撤销会恢复被移除层的定制。火焰开关的撤销也会恢复实际火焰动画。
- 再次点击当前款式可恢复该预设完整搭配；原来同名款式会直接忽略点击。
- 连续调整糕体／奶油颜色时复用原材质和纹理，只更新颜色值；保留低矮五瓣奶油花和原有星砂预算。
- 下层糖饰摆在奶油外缘，避免被更上层糕体遮住；选层标记视觉保持小巧，透明点击区域仍至少 44px。

编辑面板状态统一到现有体验 store，避免场景选层与面板分类不同步。动画继续由统一时钟驱动，暂停时主动编辑仍可完成。当前不保存到 localStorage；刷新恢复默认，重播保留本次定制。

## 实际验收

固定 pnpm 11.25.0；依赖与锁文件未升级。生产构建通过，使用本机 Chrome 155.0.8059.39 + 现有 Playwright 访问 `http://localhost:4173/?qa=1`。Browser plugin 未列出，沿用已安装的 Playwright，无新装测试依赖。测试期间不替换构建产物。

[逐层编辑专项](qa-layer-editor/results.json) 的 13 项检查全部通过：逐层独立性与 3D 标签选层、暂停编辑、撤销重做与快捷键、恢复单层、删层撤销与新分支、整体控件覆盖规则、同款恢复、真实画面改色与资源稳定、火焰恢复、许愿吹灭及重播、三种手机布局、开场定制、低性能三层预算与控制台健康。

原有 [第二阶段 20 项](qa-layer-editor-stage-two/stage-two-results.json)、[基础功能 14 项](qa-layer-editor-regression/results.json)、[分层组合 11 项](qa-layer-editor-assembly/results.json) 同样全部通过，累计 58 项。本轮按顺序检查，未并发多个 GPU 浏览器造成性能干扰；在最后的小尺寸标签和下层糖饰位置修正后，重新构建并跑完上述 13 项专项。实际查看最终桌面、手机与合拢截图，确认糖饰可见、标签视觉收敛。

连续 20 次改色的三层场景保持 66 几何体／43 纹理；用冻结画面前后 canvas 像素哈希确认实际渲染变化。不是只检查配置数据。手机检查使用 390×844、375×667、412×915 的电脑模拟视口，非实机性能结论。触摸区域至少 44 CSS px；场景与面板不重叠、无横向溢出。

低档定制三层的实际 GPU 点数仍为 2774，表面星砂总预算 1000、DPR 1，没有按层数翻倍。普通蜡烛五轮重播稳定在 56 几何体／39 纹理，数字蜡烛五轮为 59／39；与当前层数和装饰对应的资源数可不同，检查的是同一场景多次重播不增长。

历史两条 WebGLProgram 编译 warning 仍原样保留，未宣称零警告；摄影级材质与实机软键盘／性能仍需独立验收。没有把当前程序化模型标记成摄影级完成。
