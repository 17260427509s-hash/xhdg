- 0–2 秒是拍摄设备移向屏幕，2–10 秒是卡片爱心和进入入口；保留礼物仪式感，重新实现极简星空开场。
- 10.5–13 秒可见圆柱蛋糕、奶油边、暖焰与上升金色火星；彩色大点和细白星尘有明显尺寸差。
- 13–15 秒面板打开、蛋糕缩小、部件分层；15–26 秒频繁变更造型、层数和装饰。此部分按第二阶段范围保留模型组合入口，不提前加入编辑 UI。
- 26–27.5 秒关闭编辑器；约 28 秒火焰消失、彩纸扩散，29.5–31.37 秒浮层祝福渐显。原片无法证明麦克风、数据库或分享能力，也没有完整显示本项目要求的 4.5 秒点燃及 7 秒高潮，所以这两段按 PLAN.md 原创实现。

## 实现前视觉规则

- 背景为近黑 `#050507`，远景稀疏；保留黑色间隙。
- 蛋糕蓝紫，奶油象牙白，单根暖金蜡烛；暗紫薄底盘与细金边。
- 桌面底栏约 77px，最大 1110px，磨砂近黑面板、细紫灰边框。主按钮淡薰衣草紫；无设置或音乐占位。
- 原生中文无衬线文字；顶部“给 小雨”，底部“星河生日蛋糕”“拖动旋转”“暂停”“重播”“开启生日惊喜”。开场与高潮文案按 PLAN.md。
- 手机全宽主按钮与上方安静控制行分离；触摸区域至少 44px，动态视口和安全区。蛋糕与星轨在上半至中上区域，不裁切稳定场景的轨道。
- 三条轨道分别承担高处斜轨、中部轨和底部低轨；细线与大小不同的轨道星尘一起运动，并参与正常深度测试。
- 近景蓝、粉、青、金粒子比最初手机版概念图更显著；远景不随之堆密。

## 已修正的视觉差距

| 初次实拍发现 | 修正 |
| --- | --- |
| 奶油被过强灯光照成纯白，缺乏层次 | 降低主光与环境光；Bloom 阈值高于普通材质，只提升特定火焰、环与粒子亮度 |
| 奶油花法线朝内、出现暗三角 | 修正几何并改为真实变截面螺旋挤花 |
| 一条轨道近乎侧向，投影过直 | 调整三维倾角，第三轨下移至底部，形成不同层次 |
| 手机由于相机较远，近景星点显得过小 | 保留手机 300 粒子预算，补偿点尺寸；强化彩色近景与微小星芒 |
| 彩点分散得太远，包围感不足 | 向蛋糕及轨道包络聚集，保留轮廓前的间隙 |
| 蛋糕表面过于光滑 | 添加实时生成的凹凸纹理、云状蓝紫着色和实例化糖粒 |
| 贴近底部缺少蓝紫气氛 | 增加程序化着色的淡蓝紫底部光晕 |

## 材质与画面边界

概念图是离线生成的拟真渲染。当前使用可旋转的程序化糕体、几何奶油、shader、灯光和有限 Bloom 实现相同的配色、构图、控件与星河逻辑；不会将概念图作为背景、蛋糕贴图或视频播放。程序化奶油微观质感与概念图的摄影级细节仍有差异，验收报告不把它表述为逐像素一致。

技术配对依据：[R3F 官方安装说明](https://r3f.docs.pmnd.rs/getting-started/installation)（React 19 配 R3F 9）；材质亮度选择依据：[React Postprocessing Bloom](https://react-postprocessing.docs.pmnd.rs/effects/bloom)。完整依赖版本见 galaxy-cake/pnpm-lock.yaml。
