# 第一阶段摄影级视觉精修记录

日期：2026-11-02（Asia/Shanghai）。基线为 `67ffd4c`，本轮在现有应用上精修，没有重新生成工程、升级依赖或加入第二、三阶段功能。

## 实际修改

| 部位 | 基线问题 | 本轮处理 |
| --- | --- | --- |
| 滴落奶油 | 滴边节奏规则、轮廓接近重复波浪 | 保留连续封闭边缘，改变滴落间距、深度、宽度、侧向偏转，平滑 UV 接缝法线 |
| 裱花 | 扭转锥面的螺旋条纹像多层薄片，暗纹突出 | 改为一条连续的七瓣花嘴奶油管，沿 2.3 圈渐收螺旋挤出；相邻圈轻微重叠、末端收尖，实例间有轻微位置、旋转、比例变化 |
| 糕体 | 大块云纹和未过滤凹凸像粗糙塑料 | 压低大块云纹，调整为更深的蓝紫色；细孔贴图使用线性过滤、mipmap 和各向异性，降低凹凸强度 |
| 糖粒与星砂 | 细粒过于均一，反射方向固定在观察空间 | 保留实体金色糖粒，增加粒径差异；星砂根据主光的世界方向转换到观察空间计算半角反射，减少常亮底色，使切面闪光随视角变化 |
| 火焰 | 细长轮廓、外焰与核心层次不足 | 沿用体积积分，改进多尺度密度噪声、暖白核心、橙色外层、弯曲和微小伸缩；伸缩时固定焰根在烛芯处 |
| 星河 | 大亮点像光球，微粒分布较均匀 | 缩小宽泛光晕、保留少量衍射亮星；细尘向底部环带集中，增强深度与包围感；三轨按各自色调发光，减弱连续线条 |
| 布光与底盘 | 折痕暗部生硬，底盘偏厚、纹理太抢眼 | 使用环境柔光、较温和的主光和更轻的 AO；采用原生柔影，移除原 PCSS shader 注入；奶油加入轻微暖色包裹光近似，底盘改为更薄弧面与低对比釉面 |

奶油包裹光是实时散射近似，**不是完整物理次表面散射或离线路径追踪**。所有场景内容仍为实时网格、材质、shader 和 GPU 粒子。没有在运行时加载参考图、蛋糕图片或预渲染视频。

## 启动和验证方法

使用现有干净副本快进同步到 main，Node.js `24.17.0`，`pnpm 11.25.0`：

```powershell
cd galaxy-cake
pnpm install --frozen-lockfile
pnpm dev
```

开发版：<http://localhost:5173/>。已先使用 Codex 内置浏览器打开、进入、暂停并观察真实页面，保存了基线画面。

生产验证另行执行：

```powershell
pnpm build
pnpm preview
```

生产版：<http://localhost:4173/>。构建完成后再开始测试，回归期间没有重新构建或替换产物。包和锁文件均未修改。构建有既有的 Three.js / renderer 分包大于 500 kB 提示，未为消除提示改动无关打包策略。

自动回归使用仓库现有 Playwright 脚本及本机 Chrome `155.0.8059.39`。会话没有独立 Browser 插件技能；先使用内置 IAB 验证，再用既有脚本完成需要固定尺寸、触控模拟、时钟和资源统计的回归。使用 Codex 已捆绑的 Playwright，没有安装额外测试依赖。

可复现命令（先启动生产预览；`NODE_PATH` 指向本机可用的 Playwright，不要求另一台电脑使用相同绝对路径）：

```powershell
$env:NODE_PATH = '<安装了 Playwright 的 node_modules 目录>'
$env:QA_OUTPUT = (Join-Path (Resolve-Path ..).Path 'docs/qa-polish')
$env:QA_URL = 'http://localhost:4173/?qa=1'
node scripts/verify-browser.cjs
node scripts/concept-shots.cjs
```

`concept-shots.cjs` 现在也记录控制台 warning，避免仅收集 error 而遗漏 GPU 编译器提示。新环境的 Playwright 安装方法见 CONTINUE-HERE.md。

## 实际验收结果

- TypeScript 与生产构建通过。
- 原有 **14 项回归全部通过**，覆盖页面身份、非空与无错误浮层、暂停、暂停时拖动、继续、5 秒自动旋转恢复、五轮重播、手机触控、低档预算、减少动态效果、隐藏页时钟、自动降档、控制台错误和 WebGL 兜底。
- 五轮重播均为 **49 个 geometry、39 个 texture**，无逐轮增长。
- 桌面源 Points 仍为 **8,706**；AO 与颜色两次绘制统计为 **17,412**。手机为 **5,280**，低档为 **2,774**。没有增加既有预算。
- 390×844、375×667、412×915 的滚动宽度不超出视口，底栏按钮宽高均至少 44px 且位于可视区域。
- 1585×992、DPR 1 的桌面截图与 390×844、DPR 1.5 的手机截图已生成；暂停后改变视角并保留火焰局部、斜视截图。
- 回归及原尺寸截图中 `errors` 均为空。原尺寸截图首次 GPU 编译记录了两条 ANGLE 驱动 warning，包含梯度循环和浮点精度/除零提示；保留完整原文于 `final-visual-check.json`，没有通过过滤日志将其隐藏。随后独立 shader 编译诊断未复现日志；不据此把首次警告改写成“没有警告”，也不把它未经定位归因为业务 shader。

本机短时采样：

## 原尺寸视觉对照

基准：[photographic-reference.png](../design/photographic-reference.png)。修改前：[基线桌面](qa-polish-baseline/desktop-native.png)。修改后：[最新桌面](qa-polish/desktop-native.png)、[最新手机](qa-polish/mobile-390.png)。使用 `view_image` 对参考图和实际截图进行了直接检查。

| 对照点 | 本轮结果 | 剩余差距 |
| --- | --- | --- |
| 主体与背景 | 保留深空留白、蓝紫主体、象牙白奶油、暖焰和底部星尘 | 静态概念图的光学层次和空间分布仍更丰富 |
| 奶油轮廓 | 滴边不再完全等距，螺旋管替代了薄片状条纹 | 裱花与滴边仍有程序化规律感，散射近似不等于摄影级奶油 |
| 糕体与糖粒 | 云纹更克制，实体糖粒和视角闪光分离，减少粗糙噪点 | 细孔、金箔微反射和复杂非均匀纹理仍与概念图有差距 |
| 火焰 | 暖白核心、外焰、伸缩、固定焰根及转视角体积表现保留 | 尚未把整体光学观感判定为与摄影级概念一致 |
| 星轨与亮点 | 三轨空间关系保留，亮点光球感减轻，底部星尘更集中 | 亮星形态、轨道亮度和局部密度没有与概念图逐像素重合 |
| UI、文字与手机 | 桌面栏与手机按钮布局保持，未改动 UI 文案、图标或 CSS；三尺寸通过 | 继续使用系统字体，不声称与生成图中的字体逐像素一致 |

首屏文案来源未改变，组件与样式文件无差异，没有新增标签、标题、按钮、装饰文案或第二阶段功能。固定时间与起始视角由现有截图脚本控制，随机分布继续使用固定种子；动态粒子位置不要求与概念图像素相同。

**本轮完成了计划中的视觉精修和功能回归，但摄影级视觉一致性仍不标记为通过。** 不能用 14 项功能通过或约 60 FPS 替代摄影级验收，也不能把本轮描述为已达到可销售完成度。
