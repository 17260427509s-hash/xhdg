# 随蛋糕配色的陶瓷底托

2026-11-05，基于 `7925a74`。用户指出巧克力蛋糕下面的紫色层不协调，确认巧克力配深可可底托，其他款式自动搭配柔和同色系。

## 当前效果与实现

底托保留原薄弧面几何与细金边，移除固定蓝紫星云贴图和紫色自发光。改用低反光陶瓷材质：roughness 0.58、metalness 0、clearcoat 0.12。真实光照、接触阴影和环境反射继续工作，不使用发光材质。

取 `layerAppearance(config, 0).cakeColor`，依据 sRGB HSL 连续映射：深色压暗和降低饱和度，浅色柔化；纯黑保留最低可见亮度。最底层覆盖色优先，改上层不改变底托的基础色；自定义颜色也按同一规则处理，没有固定的紫色后备纹理。巧克力为深可可，星河为纯深蓝，其他预设对应柔和同色系。

起点和终点颜色仅在配置变化时计算，每帧复用材质并按现有 `partProgress(..., 'body')` 插值；不新增时钟、React 逐帧状态、材质实例或纹理。暂停中主动编辑仍沿用现有过渡。无设置项、生日数据、分享载荷、数据库、依赖或锁文件变更；星云纹理仍供原星河糕体使用。
