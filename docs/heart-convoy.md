# 参考视频式祝福队列：动态拼成爱心

2026-11-05，基于 `c058d30`。用户确认：祝福卡片需要明显沿路径逐张推进，形成爱心后停留，等待点击进入蛋糕。不得恢复为固定位置附近淡入，也不持续绕圈或整体呼吸。

## 当前行为

0–1.2 秒先显示居中的“生日快乐”，文字位于爱心内部底层。1.2–5.8 秒祝福卡片从上方同一入口依次出现，向左绕过心瓣、左侧和心尖，再沿右侧回到顶部。所有已经出现的卡片持续向前移动，后续卡片跟随，领头卡片始终在最上层；文字保持正向，仅有轻微倾斜。末段连续减速至停止，5.8–6.5 秒再显示中央祝福卡和进入按钮。

桌面 48 张、手机 32 张。完成后每张卡片位置与角度保持不变，爱心整体也不缩放。保留浅粉奶油配色、原创短祝福、中央定制内容和既有点击进入蛋糕流程。跳过／减少动态效果直接显示完成画面；定制面板或后台冻结时间，恢复后继续；蛋糕重播不重复开场。

## 实现

`openingCards` 提供队列进度偏移，而不是每张卡片的固定终点。`createHeartPath` 根据容器实际宽高预采样心形与累计弧长，逐帧按距离查找位置；非正方形手机路径也按实际 CSS 像素匀速。采样复用输出坐标对象，不在帧内创建数组或读取布局。

`BirthdayOpening` 使用一个共享 GSAP 推进进度，由现有引擎时钟驱动，每张卡片减去自己的队列偏移。ResizeObserver 只在尺寸变化时重建路径；大小或设备档切换不重置开场时间。停止后跳过卡片样式更新，退出后注销观察器、帧订阅与时间线。不新增 RAF、定时器、运行依赖、路由或数据格式；QA 的被动 rAF 采样只在测试浏览器中注入。
