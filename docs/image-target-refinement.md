# 按用户近景图片调整

> 此文件记录此前版本。当前按用户最新澄清专门精修发光星砂、火焰和粒子，结果见 [effects-polish.md](effects-polish.md) 与 `qa-fine/`。

2026-11-01。直接视觉目标为用户提供的 [`design/user-reference.png`](../design/user-reference.png)，原图 353×391。此目标优先于此前的概念图和上一轮凭视频概括的处理。

## 对照修正

| 图片中的特征 | 这轮实现 |
| --- | --- |
| 偏灰的背景 | 稳定场景改为 `#29272e`；开场仍从黑色淡入 |
| 比细尘明显大得多的蓝、黄、粉、青圆点 | 调整点尺寸分布，增大大圆点，保留小点和极少量小五角星；手机单独校正尺寸，避免大星形遮住主体 |
| 糕体前后都被彩点包围 | 近景分布更多集中到糕体高度，保留前后深度测试；没有用二维覆盖图片替代 |
| 深蓝糕体上的明亮蓝色星砂 | 多尺度云纹增加局部蓝色辐射光，增强微小闪烁星砂与少量较亮星点 |
| 紫色顶面中央的金色光池 | 新增贴合真实顶面的程序化暖光池，亮核与外围橙金渐变独立控制 |
| 更白、更连续的奶油边 | 调整为 40 颗较大的柔和奶油珠，降低光滑反射、增加克制的暖白亮度 |
| 火焰上方一整束金色火星 | 增加火星，随机化出生相位，使火星分散上升，修正此前沿一条螺旋线排列的问题 |
| 暖焰外层明显的橙色氛围 | 扩展实时火焰高度与橙色光晕，仍保留摆动和白黄核心 |
| 高处斜轨跨过火焰周围 | 上提斜轨，使其环绕到火焰高度，保持另外两轨包围糕体和底部 |
| 糕体稍高，主体位于包围粒子偏下部分 | 糕体竖向增高 12%，相机目标小幅上移，保持底栏可用 |

火焰放大后，桌面高潮与祝福状态的 3D 视口向下让出文字区域，避免暖焰直接覆盖祝福；稳定观看构图不受这项调整影响。

以上都是实时几何、ShaderMaterial、PBR 材质与真实三维粒子。图片只作为对照资料，不加载为背景或蛋糕贴图。相机仍可手动拖动，观察角度和运动时间会使瞬时画面不同，不把实拍照片描述为逐像素复制。

## 验证与证据

- `pnpm build`：TypeScript 和 Vite 构建通过。
- 完整浏览器结果：[`qa-image/results.json`](qa-image/results.json)。开场、旋转、暂停/继续、5 秒自动旋转冷却、高潮、祝福和重播通过。
- 五次重播：每轮 48 个几何体、23 个纹理，未观察到对应 GPU 资源计数增长。
- 390×844、375×667、412×915：无横向溢出，触摸区域至少 44px；触摸操作流程通过。
- 实际 GPU Points 总数：桌面 8706、手机 5280、低档 2774。受控低帧率时自动降档通过，包含火星、体积细尘和糕体星砂的真实数量减少。
- 本机 Chrome 短窗口测量：桌面稳定 59.90 FPS、庆祝 59.45 FPS；390 手机模拟稳定 59.66 FPS、庆祝 59.74 FPS。正常流程零应用、资源或 shader 错误。
- 最后微调五角星轮廓、手机大圆点尺寸、暖光池与高处斜轨后，再次构建，并补做最终桌面、手机实拍和高潮重播；结果见 [`qa-image/final-visual-check.json`](qa-image/final-visual-check.json)。
- 最终截图：[`qa-image/desktop-native.png`](qa-image/desktop-native.png)、[`qa-image/mobile-390.png`](qa-image/mobile-390.png)、[`qa-image/message-final.png`](qa-image/message-final.png)。

已使用 `view_image` 查看目标原图与最终截图，对照背景、糕体比例、彩点大小、密度、顶面光池、奶油边和火星。用户当前内置预览也已刷新并打开新版稳定场景。正常页无障碍树没有备用 WebGL 错误文案。
