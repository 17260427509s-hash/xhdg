# 第一阶段验收记录

> 此文件和 `qa/` 是初次实现的历史验收。用户看过初版后要求视觉更接近视频，已进行主视觉重做；最新结果以 [visual-refinement.md](visual-refinement.md) 和 `qa-refined/` 为准。原初版截图保留用于对比。

日期：2026-11-01（Asia/Shanghai）。应用：`galaxy-cake/`。本次完成第一阶段八项核心体验；第二、三阶段未实施。

## 实际运行与结论

已运行开发服务 `http://localhost:5173/` 和独立生产预览 `http://localhost:4173/`。`pnpm build` 通过 TypeScript 与 Vite 生产构建。首轮开发版人工截图调整后，在生产预览上重新执行浏览器验收，结果见 [`qa/results.json`](qa/results.json)。

本会话没有 Browser 插件，使用本机 Google Chrome + Playwright。通过实际原生按钮、鼠标拖动和手机触摸输入完成操作。截图由浏览器真实渲染保存，并使用 `view_image` 直接查看原始概念图和最终截图，核对构图、糕体、奶油、火焰、三轨、彩点、Bloom、文字与控制栏。视觉差距及修改记录见 [`implementation-notes.md`](implementation-notes.md)。

八项功能及下列浏览器检查通过。程序化材质和概念图的摄影级细节仍有差异，不宣称逐像素一致；手机为桌面浏览器模拟，尚未验证 iPhone、安卓真机性能，不将第一阶段称作正式销售成品。

## 帧率与自动降档

测量环境为本机 Chrome；通过真实 requestAnimationFrame 间隔采样。稳定场景采样约 2.5 秒、庆祝约 3 秒，首次编译预热不纳入。这是短窗口观测，不代表所有设备持续性能。

| 场景 | 平均 FPS | 帧时 P95 |
| --- | ---: | ---: |
| 桌面稳定 | 59.79 | 16.9ms |
| 桌面庆祝 | 59.74 | 16.8ms |
| 手机 390×844 模拟稳定 | 59.89 | 16.9ms |
| 手机 390×844 模拟庆祝 | 59.70 | 16.8ms |

- 桌面近景/远景/爆发为 600/700/350；GPU 实际 Points 数 1678（另含 28 火星）。
- 手机为 300/400/220，DPR 上限 1.5。
- 低档为 150/300/120、DPR 1，并降低后期分辨率。GPU 实际 Points 降为 598，不只是变更档位标签。
- 对浏览器施加每帧约 48ms 的受控负载，稳定阶段测得约 20.63 FPS，应用自动降为低档。逻辑未使用测试专用强制设置；强制 URL 低档与自动降档分别检查。
